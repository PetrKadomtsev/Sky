# Проект "Виджет банковских операций"

## Описание:

Проект "Виджет банковских операций" - это виджет который рабоает с данными карт и счетов, шифруя часть строки для безопасности.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/PetrKadomtsev/Sky.git
cd Sky
```

2. Установите зависимости с помощью Poetry:
```
poetry install
```

## Использование:

Основной скрипт проекта — main.py. Он предоставляет функции для:​

Фильтрации операций по статусу (filter_by_state)

Сортировки операций по дате (sort_by_date)

Маскировки чувствительных данных (mask_sensitive_data)

Преобразования форматов дат (convert_date_format)

## Тестирование:
Для запуска тестов используется фреймворк pytest.

Как запустить тесты:

Убедитесь, что зависимости установлены (например, через Poetry):


```poetry install```

Запустите тесты командой:


```poetry run pytest```

Все тесты находятся в директории tests/.
